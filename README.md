# 성 크리스토퍼 (St. Christopher) v0.6

대한민국에서 현재 위치 또는 사전 검색으로 관할 천주교 교구와 교구장을 확인하는 Android 앱입니다.

## v0.6 핵심 변경

- 앱 표시 이름을 **성 크리스토퍼**로 변경
- 교구장 원격 데이터 주소를 실제 GitHub 저장소에 기본 연결
  - `https://raw.githubusercontent.com/gtgp0903/KoreaDioceseLocator/main/data/remote_data.json`
- 별도 `gradle.properties` 설정 없이도 기본 원격 갱신이 작동하도록 구성
- `KDL_REMOTE_DATA_URL` Gradle 속성을 지정하면 기본 URL을 덮어쓸 수 있음
- 앱 실행 시 캐시된 교구장 데이터를 먼저 적용한 뒤 원격 데이터를 확인
- 인터넷이 없거나 원격 확인이 실패하면 마지막 정상 캐시 또는 앱 내장 데이터를 사용
- 원격 `boundaryVersion`이 앱 내장 버전보다 높으면 **교구 관할 정보 업데이트 필요** 팝업 표시
- 대한민국 밖에서 GPS 위치가 확인되면 **서비스 지역이 아닙니다** 안내
- 교구장 직무대행은 **(교구장을 기억하지 않음)** 표시
- 교구장 자료 안내 문구를 고정 날짜 대신 **앱 실행 시 자동 확인**으로 변경
- CBCK 자동 수집기는 15개 지역교구를 명시적 허용 목록으로 필터링하여 군종교구/기타 관할이 섞여도 오작동하지 않도록 보강

## 자동 갱신 구조

1. GitHub Actions가 매일 한국천주교주교회의 온라인 주소록을 확인합니다.
2. 15개 지역교구가 모두 정상 파싱된 경우에만 `data/remote_data.json`을 갱신합니다.
3. 앱은 위 GitHub Raw JSON을 실행 시 확인합니다.
4. 교구장 또는 직무대행 변경은 앱 업데이트 없이 자동 반영됩니다.
5. 관할지역 설명이 변경되면 `boundaryVersion`이 증가합니다.
6. 기존 앱은 더 높은 경계 버전을 확인하면 앱 업데이트 필요 팝업을 표시합니다.

## 오프라인 동작

- 교구 판정 규칙과 기본 교구장 명단은 앱에 내장됩니다.
- 마지막으로 정상 수신한 원격 JSON은 기기에 캐시됩니다.
- 인터넷이 없는 캠프·피정지에서도 마지막 정상 데이터로 계속 사용할 수 있습니다.

## 주요 기능

- GPS 현재 위치 확인
- Android Geocoder를 통한 국내 주소 확인
- 대한민국 밖 서비스 제외 안내
- 현재 위치의 관할 교구/교구장 표시
- 지역명 또는 교구명 사전 검색 탭
- 교구장 직무대행 시 `(교구장을 기억하지 않음)` 표시
- 교구장 정보 원격 자동 갱신
- 교구 관할 변경 감지 시 앱 업데이트 안내

## GitHub Actions

워크플로:

`.github/workflows/update-cbck.yml`

자동 실행 외에도 GitHub의 **Actions → Update CBCK diocese data → Run workflow**에서 수동 실행할 수 있습니다.

## 안전장치

주교회의의 공식 정보를 기준으로 하되, 수집 프로그램 자체의 파싱 오류가 정상 데이터를 덮어쓰지 않도록 합니다.

- 15개 지역교구 명시적 허용 목록 사용
- 모든 지역교구의 교구장/직무대행 및 관할지역이 정상 파싱되어야 함
- 하나라도 실패하면 JSON 갱신 및 커밋 중단
- 군종교구 및 다른 교회 관할은 GPS 지역교구 데이터에서 제외
- 면적 숫자만 바뀐 경우는 경계 변경으로 취급하지 않음

## 현재 경계 판정 방식

현재는 행정구역 규칙을 이용합니다. 시흥·안산, 동해·평창처럼 한 시·군에서 교구가 갈리는 일부 지역은 세부 경계 확인이 필요하다고 표시합니다. 다음 단계에서는 공식 행정구역 경계 GeoJSON을 내장해 GPS 좌표 기반 polygon 판정으로 개선할 예정입니다.
